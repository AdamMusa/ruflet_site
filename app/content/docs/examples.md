# Example Gallery

Use these complete documentation examples as starting points for application
features:

- [Calculator](/docs/tutorial-calculator): buttons, state, input handling, and targeted updates.
- [ToDo](/docs/tutorial-todo): forms, task collections, filters, and full-screen rerendering.
- [Solitaire](/docs/tutorial-solitaire): domain objects, gestures, absolute positioning, and larger app organization.
- [Charts and Canvas](/docs/charts-and-canvas): charts, drawing primitives, and interactive canvas input.
- [Maps](/docs/maps): tile layers, markers, circles, and shapes.
- [Services and Device APIs](/docs/services-and-plugins): files, sharing, storage, permissions, sensors, and protected device access.
- [Rails Integration](/docs/rails-integration): mount Ruflet applications inside Rails.

## Start an example project

```bash
ruflet new example_app
cd example_app
bundle install
bundle exec ruflet run main.rb --web
```

Replace `main.rb` with an example or build it step by step from a tutorial.
Use the control reference when you need the complete property and event list
for a specific control.
